# Dynamic-DCFC-ISO-15118-OCPP-Co-Simulation
A Software-in-the-Loop (SIL) co-simulation bridging MATLAB/Simscape power electronics with cloud-based OCPP telemetry. Features a custom Python UDP bridge connecting an 800V DC Fast Charger model to a local SteVe backend for real-time ISO 15118 dynamic power negotiation and smart-grid load management.
